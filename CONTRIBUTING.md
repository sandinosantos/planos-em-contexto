# Como contribuir

1. Crie uma branch descritiva a partir de `main`.
2. Para textos, perguntas, fontes e regras editoriais, edite `dist/js/content.js`.
3. Para aparência, edite `dist/css/style.css`.
4. Faça uma verificação local antes de abrir o pull request.
5. Explique no pull request quais temas foram alterados e quais fontes sustentam a mudança.

Não inclua credenciais, tokens, dados de visitantes ou arquivos ZIP. O endereço público do site só deve ser atualizado depois de uma revisão da alteração.
